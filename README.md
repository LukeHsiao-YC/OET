# OET Ward Round

OET Medicine 每日練習網頁（單一 HTML 檔，直接用瀏覽器開啟 index.html 即可）。

- 單字與間隔複習、改寫（paraphrasing）、略讀／掃讀練習
- 五份 OET 官方 Sample Test，作答時同步練習上述技巧

**僅供個人使用。** 本檔包含 OET 官方模擬考內容，版權屬 OET（Cambridge Boxhill Language Assessment），請保持此 repo 為私人，勿公開或分享。

練習進度存在瀏覽器的 localStorage，不同網址（例如 Claude 頁面與 GitHub Pages）之間不會同步。
